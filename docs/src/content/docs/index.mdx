<div class="lg-features not-content">
  <div class="lg-feature">
    <h3>Oblique splits</h3>
    <p>Every node also tries random 2–3-feature combinations <code>w·x ≥ t</code>, so diagonal structure takes one split instead of a staircase.</p>
  </div>
  <div class="lg-feature">
    <h3>Deterministic to the bit</h3>
    <p>Integer arithmetic on 16-bit feature codes and counter-based randomness: the same seed gives the same model on any machine and thread count.</p>
  </div>
  <div class="lg-feature">
    <h3>Two tree shapes</h3>
    <p>Leaf-wise trees like LightGBM, or symmetric (oblivious) trees like CatBoost, both with oblique splits.</p>
  </div>
  <div class="lg-feature">
    <h3>Native categories</h3>
    <p>LightGBM-style set splits and CatBoost-style ordered CTRs with feature combinations. Unseen categories and NaN handled the same way at prediction time.</p>
  </div>
  <div class="lg-feature">
    <h3>scikit-learn compatible</h3>
    <p>Passes <code>check_estimator</code>; works with pipelines, grid search and cross-validation. Exact pickling and JSON models.</p>
  </div>
  <div class="lg-feature">
    <h3>Fast prediction</h3>
    <p>Predictions run on <a href="https://misterekkk.github.io/lignum/">lignum</a>'s binned kernel, bit-identical to miter's own evaluator.</p>
  </div>
</div>
